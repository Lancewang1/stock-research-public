# MS 隐含假设基准

按用户要求，以 MS 2026-10-29 的 Cloud 收入和营业利润作为条件反推目标。它是情景起点，不是独立预测，也不是 MS 披露的底层经营假设。

收入：保持 AI 客户预算、Google 份额、容量、价格及 TPU 交付种子参数不变，企业服务收入 = MS Cloud 总额 − AI 服务收入 − 独立 TPU 收入，再逐季反推企业服务环比增长。Workspace/传统 GCP 内部比例仍沿旧结构代理。也可显式选择固定服务收入、改为反推 TPU 交付量；两种方法不能同时识别全部参数。

利润：保持收入结构、折旧、SBC及参考费率结构，现金成本倍率 =（Cloud收入 − MS Cloud营业利润 − Cloud D&A − Cloud SBC）÷ 参考直接现金成本与现金经营费用合计。倍率统一作用于各业务现金成本，不作用于折旧与SBC。默认额外未分配成本为零。

|季度|隐含企业服务环比增长|现金成本倍率|
|---|---:|---:|
|2026Q4|13.51%|0.9200|
|2027Q1|20.68%|0.9422|
|2027Q2|19.06%|0.8439|
|2027Q3|41.68%|0.8685|
|2027Q4|1.31%|0.7835|

高增长或低倍率提示固定条件可能需要重新研究，数学可行不代表经济上合理。MS Cloud营业利润本身亦为分部残差，不是独立利润率证据。集团各项成本通过冻结的非Cloud共享成本剩余保持与MS基准勾稽，不代表费用已全部按业务识别。

用户修改后不自动重新拟合。只有主动点击反推并应用才更新所选参数；恢复基准、保存、导出及导入仍可用。收入情景需点击应用到盈利模型，才向上表传导。历史实际值锁定，2028只保留年度延展。

重建顺序：build_cloud_inputs.py --build（原始输入后自动调用build_ms_baseline.mjs），build_profit_inputs.py，build_dashboard.py。离线分发可直接使用固定案例构建HTML。原研究参数保存在researchParameters，反推构建可重复运行。
