# Cloud 分业务盈利模型（2026-11-06）

本轮按用户要求优先完善盈利模型；使用 single-stock-workbench 工作流。基准为 MS 2026-10-29，Barclays 2026-07-24 仅提供结构参考。核查记录见 profit-model-gap-audit-20261106.md。

## 计算链与输入

2026Q4–2027Q4：Workspace、传统 GCP、AI 云服务、独立 TPU 交付收入合计为 Cloud。初始 Workspace/TPU 份额取旧 Barclays，应用到最新 MS Cloud 总额；余下 GCP 按 AI 60%/传统40%拆分，属于研究假设。历史不生成四块拆分；2028沿用年度延展。

直接成本和现金经营费用以各业务收入乘费率生成，不含折旧摊销与SBC。AI第三方成本=AI收入×第三方收入份额×采购成本率；自有运营成本=AI收入×剩余份额×自有成本率。所有业务费率、Cloud资产分配和SBC份额均为研究参数，尚无可验证直接披露，不标作共识。

集团折旧=服务器资产代理×倍率÷年限÷4+其他资产代理×倍率÷年限÷4。资产代理由MS折旧、Barclays分类折旧构成及年限反推，不是已核实资产原值；固定尺度适用于年限敏感性，不构成逐期新增、退役、投产的资产滚动模型。摊销沿MS固定。D&A在COGS及R&D之间分配；Cloud再分Workspace/传统/AI，独立TPU交付不分配自有云D&A。

SBC按MS的COGS/R&D/S&M/G&A构成分配。Cloud分配份额可调，其业务内部按收入分摊；零收入时沿用初始结构承担SBC，不能让固定费用凭空消失。

## 固定校准项及局限

Cloud未分配成本=初始收入−直接成本−现金经营费用−D&A−SBC−MS Cloud营业利润。负数是校准收益，不是识别出的经济收益；为勾稽暂放R&D，在业务表单列。五个季度分别约−2.92/−3.00/−6.34/−7.55/−10.78bn，依赖显著，不能将该结果称为独立预测。UI显示利润贡献比例，提供归零测试。修改其他参数时此项固定不重新拟合。

后续收尾已从非Cloud营业成本拆出搜索分销TAC、网络TAC和YouTube广告/订阅内容成本，见review-lab-method.md。其余现金成本残余按非Cloud总收入缩放，再加回当前D&A/SBC；共享成本保持未分配，不声称已经识别完整业务毛利。

主表的手动毛利率、研发/销售/管理费用率优先于业务成本驱动。明细显示覆盖字段及集团额外成本差额；可一键清除本季费用覆盖。改变主表Cloud增速会清除四块收入金额覆盖，恢复初始比例缩放；下方自主Cloud应用会写入四块金额，企业服务按初始Workspace/传统比例拆分。

## SBC调节口径

调整后营业利润=营业利润+SBC；调整后净利润=净利润+SBC−相关税效应；调整后EPS=(普通股盈利分子+SBC−相关税效应)/稀释股数。仅剔除税后SBC，不剔除投资收益等项目，不称公司公布Non-GAAP。年度为季度分子之和除以按天数加权股数，跨季度桥接不是完整if-converted年度会计模型。

## 文件与验证

- `scripts/profit-model.mjs`：成本、资产年限、SBC驱动；由`model.mjs`主引擎调用。
- `assets/profit-inputs.json`：带来源单元格的精选输入；离线案例已内嵌。
- `scripts/build_profit_inputs.py`：从本地完整原工作簿审计生成精选输入。公开包不含原审计，无法在无源文件环境重新抽取；可直接用固定案例离线重建看板。
- `assets/profit-ui.js`：主盈利表下方可编辑明细，与主表共用保存/导入/重置。
- `tests/test_profit_model.mjs`：基准勾稽、结构变化、折旧不重复、SBC税效应、固定校准、零收入固定费用、历史锁定、年度汇总、保存导入。
- DOM检查使用模拟canvas，不等于浏览器渲染或视觉验收。
