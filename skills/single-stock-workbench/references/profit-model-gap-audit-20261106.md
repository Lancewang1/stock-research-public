## 1. Cloud收入与AI拆分

MS `Other Drivers!DH139=DD139*(1+DH140)`，DH140为2026Q4总体增长输入；DI139/DI140对应2027Q1。Workspace行147及GCP行155在所查未来季度DH、DI中为空。存在历史标题不等于可用的未来驱动。

Barclays `New Driver!EG102=EG114+EG127+EG120`（2027Q1）：

- EG114 GCP = EG117平均GW × EG118每GW季度收入（2700百万美元）；
- EG120 Workspace = EG123客户数 × EG124席位数 × EG125月单价 × 3；
- EG127外售TPU = EG130交付GW × EG131单位收入。

三项有独立公式，可用作结构参考，但GCP不是纯AI收入；TPU销售也不能充当全部AI Cloud收入。原表TPU销售与TPUaaS的命名存在范围歧义，仍需核实真实会计边界。我们已有客户/合同双线可以继续提供输入，不能冒充卖方已完成AI拆分。

## 2. 业务利润率：区分营业利润与毛利

MS `Non-Core Losses!DH72=DH73*DH51`为Services营业利润；`DH90=DH126-DH72-DH106-DH110`为Cloud营业利润残差，DH91再除Cloud收入取得营业利润率。2027年度ER90亦为同样残差结构。因此其Cloud利润率不是完全独立的前向驱动，更不是毛利率。

Barclays `New Driver!EG159=(EG114+EG120)-EG141-EG148`计算GCP+Workspace营业利润；EG163为其营业利润率。`EG166=EG127*EG170`计算外售TPU营业利润，EG170硬编码25%情景。它能表达业务组合对营业利润的影响，但不能改名为毛利率。Services成本仍主要为`EG83=EG87*EG77`。

Barclays `YouTube`另有按年排列的附表（U3=2027，不能用主表EG列定位）：U42总收入、U75总COGS、U80=U42−U75毛利、U84营业费用、U88=U80−U84营业利润。对全工作簿公式检索未发现其他sheet直接引用`YouTube!`或`'YouTube'!`，未证明它接入集团盈利。因此可作为独立成本结构参考，不能声称整套分业务利润桥已经完成。

GS `Income Statement!BR212=BR213*BR47`，BR213=30%，是2027Q1 Cloud营业利润率输入；Services营业利润在BR207，分部合计与集团营业利润由BR226检查。公司层面的未分配费用BR223为调节项。该口径同样不是细业务毛利。

## 3. 折旧传导：Barclays有可用骨架

2027Q1明确链路：

1. `Q PP&E!EG113=6`：服务器/网络设备混合使用年限输入；EG112为相关可折旧资产原值估计。
2. `Q PP&E!EG110=AVERAGE(EF112,EG112)/EG113/4`：服务器/网络设备折旧。
3. `Q PP&E!EG114=EG116/EG117/4`：其他资产折旧；EG117为另一使用年限假设（从前季结转）。
4. `Q PP&E!EG105=EG110+EG114` → `BS!EG110` → `CF!EG10` → `IS!EG150`（另加无形摊销CF!EG12）→ EG153 → EG161 → EG271。
5. `IS!EG25=EG271*EG272`为COGS折旧部分，`EG61=EG271-EG25`为R&D部分；分别进入EG31和EG67。
6. `IS!EG139=EG31+EG67+EG83+EG110`汇总费用，EG169=EG19−EG139形成营业利润，再进入税前利润、税及净利。

限制：EG271标签叫Depreciation Expense但实际含无形摊销，新的展示需如实区分D&A；EG272来自`BS!EG97=$AN100/$AN105`的旧期资产结构比例，不是当前公司披露的费用分配；服务器资产原值也含60%等研究分配，不能当成公司细分实绩。这里只能借用结构，分配与资产存量需重新校准。

独立算术敏感性（非Excel重算）：固定2027Q1资产原值、其他费用、税率及股数，仅把服务器/网络年限6改8：该项折旧由9.086bn降至6.815bn，营业利润增加2.272bn；按该季度15%税率、12,272.110百万股，净利增加1.931bn，EPS约增加0.157美元。未模拟其他现金流/利息反馈，不作为盈利预测或会计政策建议。

MS `Model!DH364=11.2`，`DH368=-DH363/DH364/4`可驱动集团折旧。可是`Expense Drivers!DH54=DH58*DH10`、`DH99=Model!DH34*DH104`分别以费率推COGS和R&D；DH80=DH73−Model!DH238只是事后扣出折旧的分析行。当前检查未形成Barclays式折旧直接加进各费用科目的桥；不能仅接一个折旧备查行就宣称寿命变化已传导EPS。

## 4. SBC与调整后利润：MS已具备清晰来源

MS `Expense Drivers!DH173:DH177`分配SBC至COGS、R&D、销售及管理，DH178为总额。`Model!DH128:DH131`为GAAP营业利润+SBC+其他调整；DH136:DH140为GAAP净利、税后SBC及其他调整；DH148为调整后EPS。
