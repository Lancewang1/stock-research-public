2026-11-07 用户进一步要求：预测模型中的每一个数字都标明是“假设”还是“计算结果”；点击数字后直接显示这个数的身份与来源，计算结果显示公式，假设显示来源、证据和分析。明细窗口仅显示当前点击的项目，不能同时铺开同类科目或客户。

后续本地交互进一步调整为直接显示公式、只修改底层假设，详见 [公式与假设工作流](formula-assumption-workflow.md)。下方发布验证记录保留上一轮版本；新的本地验证结果记录在该文档中。

## 数字身份

身份按当前计算关系确定。用同比假设算出的收入是只读计算结果，不提供收入金额输入框；要改变收入，修改对应同比。默认由成本驱动算出的毛利率也只读，修改成本率、费用率或分配假设。已有保存或导入的明确毛利率覆盖仍按用户假设识别，不能把计算结果伪装成假设以保留旧编辑窗口；撤销覆盖后恢复只读计算关系。

- **假设**：当前模型直接使用的参数、用户覆盖或外部模型预测输入。区分用户输入、研究情景、券商预测和默认值；外部固定预测并不代表本模型独立计算或公司已确认。
- **计算结果**：由模型内其他数字算出，只读显示本期计算关系、代入值与单位，并允许沿依赖继续追到输入假设。不能直接填结果再反推输入，也不能从分析页或旧表格绕过只读限制。
- **实际值**：历史数据只读，仍按已有来源核验范围说明；不能因可点击查看就开放修改。
- **缺失值**：显示缺失，不标成假设或计算值，不补造公式和季度数据。

季度和年度必须分别识别。年度收入和利润为季度加总，年度税率由年度税额与税前利润相除，年度股数按天数加权；这些是计算结果。2028 仅年度延展，其税率、股数等可以是年度输入，不套用不存在的季度汇总。

## 打开一个数字

弹窗首先展示所点击的科目、期间、金额、单位和身份。计算结果的公式及本期代入直接可见；假设的来源摘要与依据直接可见，完整证据和原始来源仍可继续展开。不要让用户先到另一张通用表或展开多个无关项目才能知道这个数字从哪里来。

假设依据应以连贯文字解释“为什么采用这个输入”：原始值来自何处，已有历史、合同、成本或资产信息支持什么，以及哪些精确数值仍是MS输入或研究判断。不能只列代码位置、单元格或来源名称。用户覆盖保留原始参照，但明确原证据不能直接证明用户新输入的数值；未独立核实的费率、份额和年限如实标明。

当前科目相关的真实假设编辑功能保留，计算结果本身没有填值窗口。Search收入进入同比输入；订阅拆分进入合计同比和订阅份额；业务利润进入成本率、费用率、D&A和SBC分配；年度汇总进入预测季度假设。Cloud最终同比与覆盖前的目标同比分开，MS初始条件解与客户已明确保存的输入分开。切换依赖或细分项时，窗口内容替换为新选项，保留返回路径与期间。

Cloud 明细遵循相同规则：客户参数标假设，派生预算及服务收入标计算结果；收入、容量、价格、训练预算、采购份额和确认比例各自对应来源与公式。客户测算继续先预览，再显式应用到盈利模型，不能因浏览数字而改变主模型。

## 验证范围

`tests/dom-formula-assumptions.cjs`针对计算结果只读、Search等真实驱动编辑、首层叙述依据和详细证据折叠；`tests/dom-number-provenance.cjs`继续验证完整主表非空预测数的身份标记、季度与年度分类、动态覆盖与恢复、直接可见来源/公式、单项窗口及参数传导。已有模型算术与DOM检查继续覆盖保存、导入导出、历史锁定、年度输入和Cloud显式应用。新增命令的当前运行结果以本轮实际测试记录为准，不沿用下方历史结论。

数值测试还覆盖公式依赖的前进/返回、期间保留，以及从来源窗口直接修改季度和 2028 年度税率。追踪折旧敏感性中的初始基准时，依赖参数必须继续显示冻结基准且只读，不能跳到用户当前覆盖。旧条目测试通过明确导航进入 Search、服务器年限或 Cloud 成本等单项，不能靠隐藏的同级输入完成用户工作流。

Cloud 检查区分容量与 ARR 输入、派生算力预算和确认服务收入；来源窗口直接显示对应依据或公式，移动原有输入而不生成副本。修改 Anthropic 参数后，只影响其客户结果；主盈利模型在显式应用前保持原值。

```powershell
node tests/dom-smoke.cjs outputs/googl-dashboard.html
node tests/dom-cloud.cjs outputs/googl-dashboard.html
```

测试默认使用临时目录 `stock-dashboard-qa/node_modules` 下的 jsdom，也可通过 `STOCK_DASHBOARD_QA_MODULES` 指向已有依赖目录。若测试的 HTML 路径不同，替换命令末尾参数。

这些检查运行真实内联脚本，canvas 和布局被模拟；通过非视觉检查不代表已完成浏览器截图验收。本轮不改变财务计算公式或冻结研究数据。
