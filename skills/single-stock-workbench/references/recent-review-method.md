# 2026年10–11月GOOGL事件链

`scripts/build_review_events.py`默认完全离线，读取已归档的`research.json`、`market-update.json`及`outputs/research/raw_review`，生成`assets/review-events.json`。保持研究截至2026-11-05、行情截至2026-11-04；2026-11-06补查的新闻按原始发布日期放回历史节点，检索日期另列，不伪装成当日抓取。

## 内容与时点

12个节点依次展示新增信息、预期变化、相邻交易窗口和机构反应。开头约150字结论与三个争议，底部收起预期差、机构修订、材料身份和区间收益。2024年案例由原看板继续处理。

- 10/13是十月窗口的事后局部高点。旧JPM原件、GS研究框架及Barclays/MS模型只作背景，不充当10月实时一致预期。
- 财报前新增10/19二手供应链延迟线索、10/20Cloud故障、10/23Zacks预览、10/26客户混合采购、10/27Oracle联合新闻稿及Yahoo预览。均不声称独立解释当日跌幅。10/19股价实际上涨，已在正文指出。
- 10/23Zacks的Search/YouTube/Cloud收入和10/27Yahoo的总收入/Cloud预期可按业务口径比较。两篇Cloud样本分别保留。Zacks总收入111.64bn疑似扣TAC，EPS2.94未明确GAAP，不据此算预期差；10/27EPS亦不比较。
- 10/28盘后结果与10/29完整交易日分开。10/29提交的10-Q放入`verificationRefs`，不伪装成10/28已取得的文件；AFP 16:44美东文章证明盘后结果已经公开。8-K索引只证明申报日期。
- Citi 10/29初评447与10/30更新375分开。Citizens报道10/29 10:16美东在开盘之后。无明确时分的券商日期不默认盘前已知。CMBI目标价属于GOOG C类，2026盈利下修、2027–28上修的方向分别保留。
- 10/28电话会有旧包摘要和时间位置，但无完整转录/录音可核验；10/18匿名专家仅国内行业摘要，没有Google专属样本。它们放入`supplementalRefs`或材料身份区，不进入已验证的当时公开证据。

## 价格和新闻覆盖

使用未复权收盘价，不含分红。窗口收益=`结束收盘/起点收盘−1`；相对收益为简单百分点差，不是alpha或因果贡献。成交量倍数使用终点交易日之前20个交易日的GOOGL均量，分母不含终点及之后数据。10/29为139,738,300 / 25,585,340 = 5.46165倍。

10/13–26按天检索，每次不超过100条上限；10/27从10/13–27聚合请求返回的前100条中取得完整86条，当天之后另有14条10/26记录；10/26完整数据由单日请求补足。原始响应保留原始文章时间、检索时间和公开请求参数，JSON内有文件哈希和数量。新闻覆盖不保证涵盖所有影响市场的消息，也不将同源转载当成多方确认。

## 接入

```javascript
window.ReviewV11.render(container, REVIEW, {
  onFocus: ({eventId, date, startDate, endDate, session}) => {
    // 主看板将价格图定位至startDate/endDate，并标识事件date。
  }
});
```

脚本自行注入作用域为`.rv11`的CSS，使用看板现有颜色变量，包含窄屏布局和可键盘触发的按钮/折叠区。无外部网络依赖。重复render会移除旧点击监听；返回的`destroy()`也可清理监听。无回调时日期按钮滚动到相应节点。

`sourceRefs`表示当日或此前已发布的证据，`verificationRefs`表示后续核对，`supplementalRefs`表示尚未验证完整原文或发布时间的摘录。仅发布日期不证明市场当时已经读到该材料。

## 验证

离线构建断言检查事件日期排序、唯一ID、引用存在性、来源不得晚于节点（核验/待核对材料除外）、成交量基线先于终点、全部收益计算、事前预期发布时间及预期差、盘后财报到次日价格、GOOG股类。JS使用`node --check`检查语法。主看板集成后仍须由主流程实际打开，验证日期按钮与价格图联动、深色/浅色及窄屏显示。
