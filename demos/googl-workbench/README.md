- 盈利预测：完整可编辑盈利表置顶并默认展开，其后为Cloud Revenue模型与折叠研究资料。
- 近期回撤：按日期连接新信息、预期变化、价格反应及机构观点，保留市场和行业相对表现。
- Cloud第二部分包含两条线：合同收入（验收容量、保底、额外用量及价格）和客户经济性（收入、推理费用、独立训练预算及预算覆盖）。关键证据默认可见，逐客户逐季参数可编辑。
- 假设证据审计：区分公开规模、卖方原值与人为参数；明确客户成本率、训练占比和Google份额尚无直接量化证据。
- 收入参数可编辑，支持浏览器保存、JSON导入导出、收入敏感性与MS收入目标反推。独立Capex分析已暂停展示。

官方历史总额、公开关系、卖方假设和研究情景分别标注。客户采购份额、历史拆分、设施单位成本等未充分披露；模型用于讨论假设，不能把计算结果视为已核实订单或公司指引。卖方模型版本不同，不代表同日市场一致预期。

新增最低计费比例初始为0%，表示情景暂不计保底，不表示真实合同没有承诺。训练预算独立输入，合同保底与对应使用量不重复计费。证据更新2026-11-06；Wind费用转录尚未直接核对SEC原件。
