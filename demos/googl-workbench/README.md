- 近期回撤：按日期连接新信息、预期变化、价格反应及机构观点，保留市场和行业相对表现。
- 计算结果：直接展示客户可读的公式、带单位的代入值与具体来源。例如Search收入按上年同季度收入 ×（1 + 本期同比增长率）计算，修改窗口只编辑增长率等真实假设。
- 假设依据：首层说明数值来自哪家机构、哪份材料及日期，并解释采用理由；我们自行推算或设定的部分明确标为我们的分析或研究假设。详细分析和原文记录按当前条目下拉展开。
- Cloud按企业服务、AI客户和独立TPU交付展开；合同计费与客户经济性均归到对应客户，使用相同的公式与假设工作流，预览须显式应用到盈利模型。
- 假设证据审计：区分公开规模、卖方原值与人为参数；明确客户成本率、训练占比和Google份额尚无直接量化证据。
- 假设可编辑，计算结果只读；支持浏览器保存、JSON导入导出、收入敏感性与MS收入目标反推。独立Capex分析已暂停展示。
