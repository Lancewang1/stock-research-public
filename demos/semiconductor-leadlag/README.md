# 半导体上下游 Lead–Lag Demo

[在线打开](https://lancewang1.github.io/stock-research-public/demos/semiconductor-leadlag/)

交互探索美韩 7 个半导体子板块之间的历史领先滞后关系。可切换 42 个有方向的组合、日频与非重叠月频，查看分时段稳定性和滚动相关，导出当前组合 CSV。

数据区间：2014-03-28 至 2026-05-12。原研究记录数据来源为 yfinance。本页没有实时行情，也不是交易策略回测。

## 使用

在线打开，或下载 index.html 后用浏览器打开。图表库和所需数据已内嵌，不需要 API Key、服务器或联网加载资源。

## 方法与限制

- corr(A_t, B_(t+k))；正 k 表示 A 领先 B。峰值按最高有符号相关系数选取。
- 日频保留美韩日期并集，先位移后删除缺失配对，不将休市收益填零。
- 月频为非重叠自然月对数收益，排除首尾月份；源数据缺口不补齐。
- 时间顺序前 70% / 后 30% 独立计算。全样本选出的峰值在后段的表现仅作描述性对照，不是独立样本外检验。
- 滚动相关固定为 A 领先 1 期，窗口为 252 个观测日或 24 个月。
- 篮子沿用等权个股对数收益，是研究指数而非可交易组合。存在成分事后筛选和原始数据质量限制，未做汇率统一、市场因子剔除或多重检验校正。
- 美韩收盘时差可能形成隔夜相关；相关不证明因果，也不能直接验证 capex、订单或营收传导。

manifest.json 记录数据区间、计算口径和来源快照哈希。发布包仅包含 demo 页面及说明；原始研究档案不在本目录。
